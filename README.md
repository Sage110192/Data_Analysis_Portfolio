## 📊 精选项目

### 1. 供应链SKU库存健康度 & 补货建议仪表盘 — “供应链MINI仪表盘，一眼看清畅销SKU当下库存健康度，敏捷迭代业务策略”
> Python · SQL · Tableau
> 供应链模拟数据 · 供应链SKU健康度算法 · 全国仓库健康度总舱 & SKU健康度仪表盘

- **背景**：解决需求计划后，灵活根据SKU当下最新库存健康度，敏捷迭代业务策略
- **方法**：
- 1.通过对SKU进行畅销度&健康度分类，确认补货优先级（例畅销品*紧急缺货为第一优先级），通过仪表盘一眼看到急需补货的畅销SKU，灵活敏捷根据补货建议及时补货；
- 2.跟进仓库整体健康度情况，并周期性进行算法迭代；
- 3.明确每一业务场景闭环策略：（1）对紧急缺货的SKU，灵活敏捷推进补货策略；（2）对滞销产品推进至运营部门，确认下架/促销/下沉至三四线城市市场等业务策略，形成业务闭环策略并跟进落地。
- **成果**：预估库存周转效率将提升 *%，滞销品库存成本将节省 *%（模拟数据）
